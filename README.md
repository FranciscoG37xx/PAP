# AutoRevamp — Car Customization App

A car customization menu application, inspired by the vehicle customization UI 
in Forza Horizon 5. Built as my final high school project (PAP), graded 19/20.

## About
This was my first project using Unity, C#, and Blender — all three were learned 
from scratch specifically for this project. It includes:
- 2 custom car models, modeled in Blender following tutorials
- A dynamic price calculator that updates based on selected modifications 
  (paint, wheels, spoiler)
- Save/load support for customization history

## Tech Stack
- Unity (C#)
- Blender (3D modeling)

## Known Limitations
- Some parts of the application aren't fully functional, due to the complexity 
  of combining three new technologies within the project's timeframe.
- Performance testing was constrained by the school's available hardware, which 
  struggled to run the build smoothly (single-digit FPS in some scenes).
